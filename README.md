# Fashion Garment Image Classification using CNNs

## Overview
This repository contains a deep learning project focused on classifying clothing items using image data. The solution leverages a Convolutional Neural Network (CNN) trained on the FashionMNIST dataset to automatically categorize garments such as shirts, trousers, shoes, and more.

The project is derived from a hands-on DataCamp learning experience and demonstrates a complete computer vision workflow using PyTorch.

---

## Business Context
Fashion Forward is an AI-driven e-commerce retailer aiming to streamline product categorization and inventory management.

Automated image classification enables:
- Faster onboarding of new product listings
- Improved search and recommendation accuracy
- Reduced manual labeling effort
- Scalable inventory organization

---

## Project Objectives
- Build a CNN-based image classification model
- Accurately classify garment images into predefined categories
- Evaluate model performance using standard classification metrics
- Demonstrate a reproducible deep learning pipeline
